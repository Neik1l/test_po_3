# Как загрузить проект в новый пустой GitHub-репозиторий

Выполняйте команды в терминале VS Code (PowerShell) **внутри папки клонированного репозитория**.

## Подключение

1. На GitHub откройте свой репозиторий, выберите Code → HTTPS, скопируйте URL.
2. Откройте PowerShell и введите:

```powershell
cd "$HOME\Desktop"
git clone https://github.com/USERNAME/REPOSITORY.git
cd REPOSITORY
code .
```

Если Git пишет `warning: You appear to have cloned an empty repository`, это нормально.

3. Скопируйте внутрь этой папки **содержимое** архивной папки `flashcards_variant85` (не саму внешнюю папку), включая скрытый `.gitignore`. Не удаляйте уже существующую скрытую папку `.git` из клона.

## Вариант А: понятные тематические коммиты готового проекта

Вариант подходит, если вы уже скопировали все готовые файлы. Он **не демонстрирует реальный падающий TDD-тест** в истории Git, но аккуратно разделяет проект на блоки.

```powershell
git add .gitignore README.md pyproject.toml
 git commit -m "docs: initialize project and instructions"

git add tests/test_tdd_cards.py tests/test_sessions.py tests/test_storage.py
 git commit -m "test: add unit tests for cards, sessions and storage"

git add flashcards/ main.py
 git commit -m "feat: implement flashcards CLI and study logic"

git add tests/test_atdd_acceptance.py
 git commit -m "test: add ATDD acceptance criteria"

git add features/study.feature tests/test_bdd_scenarios.py
 git commit -m "test: add BDD Gherkin scenarios"

git add tests/test_sdd_examples.py
 git commit -m "test: add SDD example specifications"

git add docs/
 git commit -m "docs: add report and commit guide"

git push -u origin HEAD
```

Пробел перед `git commit` в некоторых примерах здесь нужен только для выравнивания, PowerShell его игнорирует.

## Вариант Б: настоящая последовательность TDD (RED → GREEN)

**Прежде чем копировать готовую реализацию**, создайте README/.gitignore, сохраните коммит. Скопируйте тесты TDD без модулей `flashcards` и выполните `py -m unittest discover -s tests -p test_tdd_cards.py -v` — получите ожидаемую ошибку импорта (**RED**). Затем добавьте из архива `flashcards/__init__.py`, `models.py`, `trainer.py`, повторите те же тесты — должны пройти (**GREEN**). Это не полное движение маленькими шагами, но честно показывает факт «тесты раньше кода». Для настоящего REFACTOR следует самостоятельно внести поддерживающее рефакторинговое изменение и убедиться в сохранении результатов.

## Проверка

```powershell
py -m unittest discover -s tests -p "test_*.py" -v
py main.py
git status
git log --oneline
```

Если `git commit` просит указать данные автора:

```powershell
git config --global user.name "Ваше имя"
git config --global user.email "ваша-почта-для-GitHub"
```

Если основная ветка уже настроена и связана с GitHub, для следующих обновлений достаточно `git push`.
